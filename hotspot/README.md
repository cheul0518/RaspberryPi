# 핫스팟 버튼 웹앱 (버튼 1개)

누르면 버튼이 눌린 채로 **ON** + 핫스팟 켜짐, 다시 누르면 원위치 **OFF** + 핫스팟 꺼짐.

iOS는 웹페이지·앱이 핫스팟을 직접 켜는 걸 막아 두어서, 버튼이 아이폰 **단축어**를 실행해 켜고 끕니다.
누르면 단축어가 잠깐 실행된 뒤 이 페이지로 자동으로 돌아옵니다.

## 1. 단축어 2개 만들기 (아이폰, 한 번만)
1. 단축어 앱 → `+` → 동작 추가 → **"개인용 핫스팟 설정"** → "켜기" 그대로 → 이름 **`핫스팟 켜기`**
2. 같은 방법으로 "끄기"로 바꾼 단축어 → 이름 **`핫스팟 끄기`**
(이름이 한 글자라도 다르면 실행되지 않습니다)

## 2. 페이지 열고 홈 화면에 추가
1. 아이폰 Safari에서 웹앱 주소 열기
2. 공유 버튼 → **홈 화면에 추가** → 이름 `핫스팟`
3. 처음 누를 때 "단축어를 열겠습니까?" 같은 확인이 뜨면 허용

## 참고
- 이 페이지는 실제 핫스팟 상태를 읽을 수 없어서, 제어센터에서 따로 켜고 끄면 버튼 표시와 달라질 수 있습니다. 그때는 한 번 더 누르면 맞춰집니다.
- 단축어 실행 후 돌아올 때 Safari 탭으로 열릴 수 있습니다. 홈 화면 아이콘이 Safari로 열리게 하려면, 홈 화면에 추가할 때 "웹 앱으로 열기"를 끄세요.
